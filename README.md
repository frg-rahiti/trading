# Tahitian Trader

**Algorithmic Trading Technology**

Tahitian Trader is a premium platform for systematic trading products: MetaTrader 5 Expert Advisors, TradingView strategies, and quantitative tools.

## V1

- Premium marketing site
- MT5 EA product catalog
- TradingView strategy product
- Product performance and methodology pages
- Backtest and Monte Carlo result presentation
- Supabase authentication, database, storage and Row Level Security
- Stripe checkout and webhook-ready order flow
- Customer dashboard
- License management
- Secure product downloads
- Admin area

## Deployment

Production is deployed from `main` through Vercel. Environment variable changes require a new deployment.

## Roadmap

- V2: additional EAs, TradingView indicators and bundles
- V3: Setup Scanner, backtesting, optimization, analytics and SaaS subscriptions

## Stack

Next.js, TypeScript, Tailwind CSS, Supabase, Stripe, Vercel.

> Proprietary EA source and compiled binaries must never be committed to this public repository.
